# SectorBoost Diagnosis Tool

SectorBoost公式サイトに埋め込むための簡易診断ツール。

## Purpose

- ユーザーが簡単に売上・広告導線の課題を診断できる
- 診断結果からSectorBoostへの相談・申込につなげる
- WordPress固定ページまたはLP内に埋め込みやすい形で管理する

## Tech

- HTML
- CSS
- JavaScript

## Usage

index.htmlをブラウザで開いて動作確認する。
完成後、WordPress固定ページまたはカスタムHTMLブロックに埋め込む。
